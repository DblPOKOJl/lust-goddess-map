# 🗺️ Lust Goddess — Админ-панель клановой карты

Неофициальный инструмент для админов кланов: распределение 10 кланов по сетке 6×5 в игровом ивенте «Война кланов».

🔗 Онлайн-версия: [https://dblpokojl.github.io/lust-goddess-map/](https://dblpokojl.github.io/lust-goddess-map/)

⚠️ Это неофициальный фан-проект. Точки входа кланов взяты из игрового клиента и могут измениться после патчей.

## ✨ Возможности

- **Визуальное распределение** — крась клетки карты в цвет выбранного клана одним тапом
- **Справка по входам** — выбрал клан, и его 5 входных точек подсветятся пульсацией на карте
- **Автоподсчёт очков** — рядом с каждым кланом сразу видно, сколько очков он сейчас даёт (периметр = 500, центр = 1000)
- **Перетирание** — занял клетку не тем кланом? Просто выбери правильный и тапни по клетке — она перекрасится
- **Кастомные названия** — впиши настоящие имена кланов через кнопку «изменить», на карте будут отображаться первые 3 буквы
- **Автосохранение** — всё состояние хранится в localStorage, после закрытия/перезагрузки вкладки карта на месте
- **Сброс одной кнопкой** — ↺ в углу возвращает имена и раскладку к начальному состоянию (с подтверждением)
- **Mobile-first** — интерфейс вмещается на экран смартфона без скролла

## 📱 Как пользоваться

### Сценарий 1: «Раскидать все 10 кланов по карте»

1. В верхней части экрана выбери клан — тап по его строке. Строка подсветится в цвет клана, а на карте запульсируют его 5 входных точек.
2. Тапай по клеткам карты — они окрасятся в цвет выбранного клана, в центре появится трёхбуквенный тег (первые буквы названия).
3. Справа от названия клана видна сумма очков, которые дают занятые им клетки.
4. Чтобы выбрать другой клан — просто тапни по его строке. Повторный тап по уже выбранному клану снимает выбор.

### Сценарий 2: «Передумал — перекрасить клетку»

Просто выбери нужный клан (как в сценарии 1) и тапни по занятой клетке. Она перекрасится в цвет нового владельца, очки автоматически пересчитаются у обоих кланов. Обмена нет, только перетирание — так задумано правилами ивента.

### Сценарий 3: «Вписать реальные имена кланов»

1. Нажми кнопку **«изменить»** справа от названия клана.
2. Впиши имя в поле (или отредактируй дефолтное).
3. Для подтверждения нажми **«готово»**, Enter, или просто тапни в любом месте вне поля.
4. На карте клетка этого клана теперь показывает первые 3 буквы нового имени.

### Сценарий 4: «Начать заново»

Нажми кнопку ↺ в правом верхнем углу и подтверди. Все имена вернутся к «Клан 1…Клан 10», все клетки очистятся.

## 🧮 Механика карты

Ивент проходит на сетке 6×5:
- **Колонки:** 1, 2, 3, 4, 5, 6
- **Строки:** A, B, C, D, E

**Очки за клетки:**
| Тип клетки | Номинал |
| --- | --- |
| Периметр (ряды A и E, колонки 1 и 6) | 500 |
| Внутренние клетки (B, C, D × 2..5) | 1000 |

**Входы кланов:**
У каждого из 10 кланов есть 5 конкретных точек входа — именно через них клан физически может зайти на карту в игре. В панели входы показаны пульсацией при выборе клана и нужны **только как справка** для админа. Размещение клана на карте и его точки входа — две независимые сущности: валидацию соответствия делает сам админ, инструмент не ограничивает где красить.

**Ограничения размещения:**
- Клан может занимать любое количество клеток (от 0 до 30).
- К концу распределения админом все 30 клеток карты должны быть заняты.
- В одну клетку — один клан.

**Палитра кланов** (захардкожена по номеру, соответствует игровым цветам):
1. Циан

4. Розовый
5. Красный
6. Светло-зелёный
7. Жёлтый
